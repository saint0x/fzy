# GPU Remaining Work

1. Harden the live `metal` execution path past the first real kernel launch. Kernel package consumption, launch submission, synchronous/asynchronous waits, and basic copy-style execution now run against the live Metal backend, but the remaining work is deeper production hardening: richer data-correct kernel shapes like vector add / saxpy / relu, better pipeline caching policy, launch diagnostics that pinpoint bad bindings/layouts, resource pressure handling, and stronger runtime cleanup/error reporting. Start in `crates/driver/src/pipeline/native_runtime_support/runtime_shim/gpu.rs`, `crates/driver/src/pipeline/gpu_kernel_metal.rs`, and the shared native backend lowering/runtime entrypoints.

2. Finish the stable backend-neutral launch packet and kernel identity contract across all backends. `kernel_ir` lowering, emitted package artifacts, Metal kernel descriptor generation, and the first live launch ABI now exist, but `spirv` / `nvptx` still need to consume the same contract, and the shared ABI still needs explicit versioning for argument layout classes, backend limits, and kernel capability flags. See `crates/kernel_ir/src/lib.rs`, `crates/driver/src/pipeline/policy_artifacts.rs`, `crates/driver/src/pipeline/gpu_backend.rs`, `crates/driver/src/pipeline/gpu_kernel_metal.rs`, and `crates/driver/src/pipeline.rs`.

3. Add production gates once the live path exists. Before closing this file, the GPU stack still needs baseline kernels like vector add / saxpy / relu / image brightness, checks against unsupported fallback behavior or accidental scalarization, and stable diagnostics for host-from-device calls, unsupported device types, alias violations, barrier misuse, backend-shape rejection, and backend lowering/runtime failures. Put that coverage in Fozzy scenarios and validate each finished chunk with `fozzy doctor --deep --scenario <scenario> --runs 5 --seed <seed> --json`, `fozzy test --det --strict <scenarios...> --json`, one recorded trace, `fozzy trace verify`, `fozzy replay`, and `fozzy ci`.
